什麼是 Graph？

  • Graph 由頂點 V（vertices）和邊 E（edges）組成，寫成 G = (V,E) G1 p.16
  • 有邊相連的 vertices 叫 neighbors；degree 是連出去的邊數 G1 p.16
  • 例：V = {1,2,3,4}，E = { {1,3}, {2,4}, {3,4}, {2,3} } G1 p.16
  • 有向圖的邊有方向，分成 in-degree 與 out-degree G1 p.17
  • 例子無所不在：internet、航班、套件相依、大腦神經連結 G1 p.4-14

電腦怎麼存一張圖？

  • Adjacency matrix：用 0/1 矩陣記錄哪兩個 vertices 之間有邊 G1 p.16G1 p.18
  • Adjacency list：每個 vertex 存一串 neighbors，例如 4 的 neighbors 是 2 和 3 G1 p.21
  • Edge membership：matrix O(1)、list O(deg(v)) G1 p.23
  • Neighbor query：matrix O(n)、list O(deg(v)) G1 p.23
  • Space：matrix O(n^2)、list O(n + m)；list 較適合 sparse graph G1 p.23

DFS 的直覺：拿粉筆走迷宮

  • 講義用「拿粉筆和一條線探索迷宮」說明 DFS G1 p.26
  • 每個地點三種狀態：還沒去過、去過但出口沒探完、出口都探完 G1 p.26
  • 先盡量往深處走（go as deep as we can），過程中建出一棵 DFS tree G1 p.54
  • DFS 會找到起點能到達的所有 nodes；在無向圖中叫 connected component G1 p.52
  • 一次走不完整張圖時就重複做；有向圖也能用 G1 p.53G1 p.57

拜訪順序

  • 看 stack 頂端：還有沒拜訪的鄰居就 push，沒有就 pop（backtrack） G2 p.3
  • 圖 G 從 v3 開始，拜訪順序：v3, v2, v1, v4, v5 G2 p.4
  • 講義沒說多個鄰居時先選誰；動畫採「編號小的先」，邊是看講義圖讀出的 G2 p.3G2 p.2
看虛擬碼（G2 p.3，取自 wiki）
Algorithm dfs(v)
    s.createStack();
    s.push(v);
    mark v as visited;
    while (!s.isEmpty()) {
        let x be the node on the top of the stack s;
        if (no unvisited nodes are adjacent to x)
            s.pop();            // backtrack
        else {
            select an unvisited node u adjacent to x;
            s.push(u);
            mark u as visited;
        }
    }

看虛擬碼（G2 p.6，取自 wiki）
Algorithm bfs(v)
    q.createQueue();
    q.enqueue(v);
    mark v as visited;
    while (!q.isEmpty()) {
        w = q.dequeue();
        for (each unvisited node u adjacent to w) {
            q.enqueue(u);
            mark u as visited;
        }
    }

DFS vs BFS

  • DFS：先往深處走；非遞迴版用 stack G1 p.54G2 p.3
  • BFS：先往廣處走；用 queue G1 p.89G2 p.6
  • 兩者都會找到起點能到達的所有 nodes G1 p.52G1 p.87
  • 和樹對照：preorder／inorder／postorder 需要 stack，level-order 用 queue C5 p.22
  • BFS 的策略和 level-order 相似 G2 p.5

跑多快？執行時間

  • f(n) 是 O(g(n))：n 夠大之後，f(n) 不超過 g(n) 的常數倍 C1 p.28
  • DFS、BFS 都是 O(n + m) G1 p.56G1 p.88
  • 原因：每條 edge 最多看兩次、每個 vertex 最多拜訪一次 G1 p.55
  • 每個 vertex：O(1) bookkeeping＋O(deg(w)) 檢查 neighbors G1 p.56
Wiki：big-o、graph-representation、dfs11 / 15

DFS 與 BFS 能做什麼

  • DFS → topological sorting：相依圖必須是 DAG（沒有 cycle） G1 p.59
  • 若有邊 A → B，DFS 中 B 會先 finish；照 finish time 反序排即可 G1 p.66G1 p.67
  • BFS → shortest path：distance 是最短路徑的邊數；在 Li 裡的 v，距離就是 i G1 p.94
  • BFS → bipartite：BFS tree 各層交替塗兩色，相鄰同色就不是 bipartite G1 p.103
  • BFS 檢測 bipartite 的時間是 O(n + m) G1 p.117
