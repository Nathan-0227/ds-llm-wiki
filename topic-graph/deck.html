DFS：拿粉筆走迷宮

  • 想像你在迷宮裡，手上有粉筆和一條線 G1 p.26
  • 用粉筆記下每個地方：沒去過、去過但還有路沒走、全部走完 G1 p.26
  • 它叫 depth-first，因為會盡量往深處走（go as deep as we can） G1 p.54
  • 講義用一連串投影片，一步一步示範整個迷宮怎麼被探索 G1 p.26-41
  • 最後，從起點走得到的地方全部都會被走過 G1 p.52

動手玩：DFS

Stack（頂端在右）

拜訪順序

  • 按「下一步」，看 stack 怎麼長高、變矮 G2 p.3
  • 有新鄰居就 push（往前走），沒路了就 pop（退回來） G2 p.3
  • 從 v3 出發，走的順序：v3, v2, v1, v4, v5 G2 p.4
  • 講義沒說先走哪個鄰居；這裡選編號小的，邊是看講義圖讀出的 G2 p.3G2 p.2
看虛擬碼（G2 p.3，取自 wiki）
Algorithm dfs(v)
    s.createStack();
    s.push(v);
    mark v as visited;
    while (!s.isEmpty()) {
        let x be the node on the top of the stack s;
        if (no unvisited nodes are adjacent to x)
            s.pop();            // backtrack
        else {
            select an unvisited node u adjacent to x;
            s.push(u);
            mark u as visited;
        }
    }

BFS：飛到天上往下看

  • 講義的比喻：如果我們會飛，用鳥瞰（bird's-eye view）來看 G1 p.79G1 p.81
  • 先找一步（one step）能到的地方，再找兩步、三步（two、three steps）能到的 G1 p.81
  • 講義依「幾步能到」（steps），一步一步把點上色 G1 p.81-85
  • 規則：先把附近的走完，再往外擴（go as broadly as we can） G1 p.89

動手玩：BFS

Queue（front → back）

拜訪順序

  • 按「下一步」，看 queue 怎麼排隊 G2 p.6
  • 從隊伍前面拿出一個點（dequeue），把它還沒去過的鄰居排到後面（enqueue） G2 p.6
  • 從 v5 出發，走的順序：v5, v3, v4, v2, v1 G2 p.7
  • 同樣是 BFS，有兩種寫法：G1 用一層一層的清單 Li、G2 用一個 queue G1 p.86G2 p.6
看虛擬碼（G2 p.6，取自 wiki）
Algorithm bfs(v)
    q.createQueue();
    q.enqueue(v);
    mark v as visited;
    while (!q.isEmpty()) {
        w = q.dequeue();
        for (each unvisited node u adjacent to w) {
            q.enqueue(u);
            mark u as visited;
        }
    }

DFS vs BFS

  • DFS：先往深處鑽，非遞迴寫法用 stack G1 p.54G2 p.3
  • BFS：先往旁邊擴，用 queue G1 p.89G2 p.6
  • 兩個都能找到起點走得到的所有點 G1 p.52G1 p.87
  • 樹也一樣：一層一層走（level-order）用 queue，和 BFS 很像 C5 p.22G2 p.5

它們跑得多快？

  • 每條線最多看兩次，每個點最多去一次 G1 p.55
  • 所以時間是 O(n + m)：n 是點的數量、m 是線的數量 G1 p.55
  • O(...) 是在說：n 變大時，需要的量最多以什麼速度長（不管常數倍） C1 p.28
  • DFS、BFS 都是 O(n + m) G1 p.56G1 p.88

DFS 的用途：裝軟體要照什麼順序？

  • 裝軟體時，有些套件必須先裝別的套件才能用 G1 p.58
  • 這種「誰要先」的關係也是 Graph，而且不能繞圈（DAG） G1 p.59
  • 做 DFS，照「走完的時間」（finish time）倒過來排，就是安全的安裝順序 G1 p.67

BFS 的用途：最短距離與魚缸問題

  • 最短距離：BFS 第 i 層的點，離起點剛好 i 步 G1 p.94
  • 課前練習：Samuel L. Jackson 的 Bacon number 是多少？答案是 2 G1 p.90
  • 魚缸問題：會打架的魚不能放同一缸，兩個缸放得下嗎？ G1 p.97
  • 做法：BFS 一層塗 A 色、一層塗 B 色；相鄰的同色就放不下 G1 p.103
