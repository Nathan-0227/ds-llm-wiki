## 複雜度比較 [C7 p.47]
| Method | Worst | Average |
|---|---|---|
| Insertion Sort | n2 [C7 p.47] | n2 [C7 p.47] |
| Heap Sort | n log n [C7 p.47] | n log n [C7 p.47] |
| Merge Sort | n log n [C7 p.47] | n log n [C7 p.47] |
| Quick Sort | n2 [C7 p.47] | n log n [C7 p.47] |

## 總結
- 沒有一種方法在所有情況都最好 [C7 p.46]。
- Insertion sort 適合已部分排序或 n 很小的情況 [C7 p.46]。
- Merge sort 的 worst-case 最好，但比 heap sort 需要更多儲存空間 [C7 p.46]。
- Quick sort 的 average 最好，但 worst-case 是 O(n2) [C7 p.46]。
