# C8 · Chapter 8: Hashing（輕量）

## 章節大綱
- Array 與 tree 的效能比較，引出「能不能 O(1)」的問題 [C8 p.2]。
- Static hashing：hash table、hash functions（division、mid-square、folding）[C8 p.3-8]。
- Overflow handling：linear probing、quadratic probing、rehashing、chaining [C8 p.9-13]。
- Dynamic hashing（有 directory 與 directoryless）[C8 p.14-23]。

## 關鍵定義
- Hash function：把 key 轉成 table index，例如 h(k) = k mod 10 [C8 p.3]。
- Hash collision：兩個 keys 要放進同一個 bucket [C8 p.3]。
- Synonym：h(k1) = h(k2) 時 k1、k2 互為 synonyms [C8 p.4]。
- Open addressing 在表中依規則找沒滿的 bucket；chaining 讓每個 bucket 存一條 linked list [C8 p.9]。
- Linear probing：一格一格找下一個空 bucket，(h(k) + j) % D [C8 p.10]。
