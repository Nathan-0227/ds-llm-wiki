# C10 · Chapter 10: Efficient Binary Search Trees（輕量）

## 章節大綱
- Optimal BST：extended binary trees、search cost、建構演算法 [C10 p.2-8]。
- AVL trees 與四種 rotation（LL、RR、LR、RL）[C10 p.9-15]。
- Red-black trees：定義、性質、插入 [C10 p.17-30]。
- Splay trees（bottom-up 與 top-down）[C10 p.31-47]。

## 關鍵重點
- AVL tree 是 height balanced 的 BST，每個 node 的 balance factor 是 −1、0 或 1 [C10 p.9]。
- AVL tree 的插入與刪除可以在 O(log n) 完成 [C10 p.9]。
- Red-black tree 是 extended binary search tree，node 或 edge 塗成 red 或 black [C10 p.17]。
- 複雜度比較：AVL tree 的搜尋是 O(log n)，linked list 是 O(n) [C10 p.16]。
