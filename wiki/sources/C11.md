## 關鍵定義
- m-way search tree：root 最多有 m 個 subtrees，keys 由小到大排列，每個 subtree 也是 m-way search tree [C11 p.2]。
- B-tree of order m：root 至少 2 個 children，所有 external nodes 在同一層 [C11 p.5]。
- 2-3 tree 是 order 3 的 B-tree，2-3-4 tree 是 order 4 的 B-tree [C11 p.5]。
